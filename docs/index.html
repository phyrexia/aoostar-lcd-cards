AOOSTAR · 960×376 USB LCD

Your NAS front panel, your cards.El panel de tu NAS, tus tarjetas.

Rotating status cards for the front LCD of AOOSTAR mini PCs and NAS boxes. Pick which cards appear, in which order and for how long, from one YAML file, or write your own in a few lines of Python. Frames are drawn with Pillow and sent through asterctl. Tarjetas de estado que rotan en la LCD frontal de los mini PC y NAS AOOSTAR. Eliges qué tarjetas aparecen, en qué orden y cuánto duran desde un solo archivo YAML, o escribes las tuyas con pocas líneas de Python. Los cuadros se dibujan con Pillow y se envían con asterctl.

How it worksCómo funciona

A collector measures, a renderer draws, asterctl talks to the panel. Run them together, or split them between a host and a container.Un colector mide, un renderizador dibuja y asterctl habla con la pantalla. Corren juntos o separados entre un host y un contenedor.

Split for ProxmoxSeparado para Proxmox

The host sees every NIC, pool and disk; an unprivileged LXC only needs the serial device and a read-only bind mount.El host ve todas las NIC, pools y discos; un LXC sin privilegios solo necesita el dispositivo serie y un montaje de solo lectura.

Never staleNunca datos viejos

The state has a timestamp; if it gets too old the panel says NO DATA. History survives restarts.El estado lleva marca de tiempo; si envejece la pantalla dice SIN DATOS. El historial sobrevive a los reinicios.

Gentle on the panelCuida la pantalla

A frame is sent only when it changed; failures are retried on the next interval, never in a tight loop.Solo se envía un cuadro si cambió; un fallo se reintenta en el siguiente intervalo, nunca en un bucle apretado.

ConfigureConfigurar

One YAML file. Order is rotation order; each card has a duration and its own options. Mistakes are reported with the exact key and a suggestion.Un archivo YAML. El orden es el de la rotación; cada tarjeta tiene su duración y sus opciones. Los errores indican la clave exacta y una sugerencia.

config.yaml

language: en              # en | es
display:
  device: /dev/ttyACM0
rotation:
  default_duration: 8
theme:
  preset: dark             # dark | light, any color
cards:
  - type: cpu
    temperature_chip: k10temp
  - type: network
    interfaces: [enp1s0, enp2s0]
    units: bits              # Mbit/s | bytes = MB/s
    mode: aggregate          # or split
  - type: storage
    units: si                # TB | iec = TiB
    volumes:
      - {zfs: tank, label: Data}
      - {mount: /, label: System}
  - type: clock
    duration: 5
  - type: image
    path: /etc/aoostar-lcd/images
    enabled: false

Your own cards and picturesTarjetas e imágenes propias

From no code to full control: a command, a picture, or a small Python class loaded from the YAML.De cero código a control total: un comando, una imagen o una pequeña clase de Python que se carga desde el YAML.

hello_card.py

from aoostar_lcd import Card


class HelloCard(Card):
    type_name = "hello"
    defaults = {"greeting": "Hello"}

    def collect(self):            # on the host
        import os
        return {"processes": len(os.listdir("/proc"))}

    def render(self, canvas, theme, data):   # next to the LCD
        canvas.title("HELLO")
        canvas.text((canvas.left, canvas.top + 170),
                    self.options["greeting"] + "!", size=90, anchor="ls")

config.yaml

- type: plugin
  plugin: plugins/hello_card.py:HelloCard
  greeting: Hi

- type: custom                 # no Python at all
  title: BACKUPS
  command: [/usr/local/bin/backup-status, --json]
  refresh: 60

- type: image                  # png, jpg, webp, gif
  path: /etc/aoostar-lcd/images
  mode: contain                # cover | fit-width
  background: "#101218"
Image rights. Only display pictures you are allowed to use. The project ships no third-party artwork; the example logo and landscape were generated for it with Pillow.Derechos de las imágenes. Muestra solo imágenes que tengas derecho a usar. El proyecto no incluye arte de terceros; el logo y el paisaje de ejemplo se generaron para él con Pillow.

InstallInstalar

Three ways to run it. asterctl is installed at the pinned version in all of them.Tres formas de correrlo. En todas se instala asterctl en la versión fijada.

# asterctl: pinned release, SHA-256 checked (or --from source = cargo build)
sudo scripts/install-asterctl.sh
# the package, in its own virtual environment
sudo python3 -m venv /opt/aoostar-lcd
sudo /opt/aoostar-lcd/bin/pip install .
sudo ln -sf /opt/aoostar-lcd/bin/aoostar-lcd /usr/local/bin/aoostar-lcd
# configuration and service
sudo install -d /etc/aoostar-lcd && sudo cp config.example.yaml /etc/aoostar-lcd/config.yaml
sudo aoostar-lcd check -c /etc/aoostar-lcd/config.yaml
sudo cp systemd/aoostar-lcd.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now aoostar-lcd
# on the Proxmox host: the collector writes /run/aoostar-lcd/state.json
sudo cp systemd/aoostar-lcd-collector.service /etc/systemd/system/
sudo systemctl enable --now aoostar-lcd-collector

# /etc/pve/lxc/<id>.conf (Proxmox VE 8.1+)
dev0: /dev/ttyACM0,gid=20,mode=0660
mp0: /run/aoostar-lcd,mp=/data,ro=1

# inside the container: asterctl + package, then
cp systemd/aoostar-lcd-display.service /etc/systemd/system/
systemctl enable --now aoostar-lcd-display     # reads /data/state.json, no root
cp config.example.yaml config.yaml          # keep display.device: /dev/ttyACM0
docker compose up -d --build                # builds asterctl from the pinned commit

# or prebuilt asterctl (x86_64)
docker build --build-arg ASTERCTL_SOURCE=release -t aoostar-lcd .
docker run -d --device /dev/ttyACM0 --group-add dialout --network host \
  -v ./config.yaml:/config/config.yaml:ro aoostar-lcd
